# 实验结果目录

本目录只公开项目报告中引用的现有结果。以后运行产生的新时间戳目录默认被 `.gitignore` 忽略，确认不含密钥或隐私信息后再决定是否公开。

| 目录 | 类型 | 说明 |
|---|---|---|
| `run_20260904_152757/` | 真实 API | 旧版直接点名物体的历史实验，存在 API 错误 |
| `run_20260904_155231/` | 真实 API | 视觉指代初版；scene 04 元数据和自由文本解析规则存在问题 |
| `run_20260904_161430/` | 真实 API | Benchmark 2.1 历史正式主实验，80 次 API 调用全部成功 |
| `run_20260905_210917/` | 真实 API | Benchmark 3.1 正确图片正式主实验；80 个有效结果，累计 81 次调用 |
| `run_20260905_211828/` | 真实 API | Benchmark 3.1 `text_only` 对照；80 个有效结果 |
| `run_20260905_212030/` | 真实 API | Benchmark 3.1 `shuffled` 对照；80 个有效结果 |
| `local_dry_run_20260904/` | Mock | 早期程序管线检查，不代表模型性能 |
| `local_dry_run_v2_1_20260904/` | Mock | Benchmark 2.1 程序管线检查，不代表模型性能 |

真实结果中的原始模型输出、失败案例、汇总、运行参数、代码/数据/图片哈希和服务商请求 ID 均按实验当时状态保留。任何 API Key 都不会写入结果文件。

当前正式结论以 Benchmark 3.1 的三个 `run_20260905_*` 目录为依据。`run_20260904_161430/` 是 Benchmark 2.1 历史结果；2.1 与 3.1 的任务设计不同，不能直接比较为同一实验的重复测量。
